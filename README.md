# express-todo-list-authentication

A To-Do List web app made with JavaScript, Express, SQLite, and Handlebars.

Features: 
- User registration and login
- Password hashing with bcrypt
- Authentication using cookies and tokens
- Add and view personal tasks
- SQLite database

Tools used:
- JavaScript
- Node.js
- Express
- SQLite
- Handlebars
- bcrypt
- UUID

What I learned: 
This project helped me learn more about building a web app with JavaScript and Express. I also learned how to use SQLite databases, hash passwords with bcrypt, and use cookies and authentication tokens for user login.
